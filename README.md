# 📊 Bootcamp Dados e IA - DIO & Reclame AQUI

## 🎯 Sobre o Curso
O **Bootcamp Reclame AQUI: Dados e IA na Prática**, desenvolvido em parceria entre a **DIO (Digital Innovation One)** e o **Reclame AQUI (RA Educa)**, foca na aplicação prática de Análise de Dados, Inteligência Artificial Generativa, SQL, Python e Excel 365 voltados para a experiência do cliente (CX), eficiência operacional e gestão de reputação de marcas.

---

## 💻 Conexão com a Graduação em Ciência da Computação
A participação neste programa complementa de forma direta a formação acadêmica em **Ciência da Computação**, permitindo:
- **Aplicação Prática da Teoria:** Conectar conceitos teóricos de estrutura de dados, modelagem relacional e algoritmos a cenários reais de análise de dados corporativos.
- **Domínio de Ferramentas e Fundamentos:** Aprofundar o manuseio de ferramentas de análise e manipulação de dados, criando uma base sólida para disciplinas avançadas de Banco de Dados, Engenharia de Dados e Aprendizado de Máquina.

---

## 🚀 Impacto no Desenvolvimento Profissional
A consolidação de competências em Análise de Dados e Inteligência Artificial fortalece o perfil técnico para atuar na solução de problemas complexos do mercado de tecnologia, preparando o terreno para carreiras estratégicas em **Administração de Banco de Dados (DBA)**, **Engenharia/Análise de Dados** e **Business Intelligence**.

---
